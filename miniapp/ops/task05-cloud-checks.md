## 云端用例

使用隔离空间的两个家庭：同家庭所有者 A、普通成员 B，另一家庭成员 C。通过正常登录和邀请建立身份，不把 token/openid/菜谱全文写入证据或会话。

| 检查 | 预期 |
| --- | --- |
| A 创建，B 列表、读取、编辑 | 标题/说明/食材/步骤/可选份数时间往返；作者及家庭保持不变 |
| “盐适量”、未知份数及准备时间 0 | 原文保留、未知为 null、已知 0 分钟保留 |
| C 猜中 ID 读取/更新，伪造作者/归属 | 不泄露跨家庭数据；资源统一 NOT_FOUND，额外字段拒绝 |
| 两账户同时编辑同一版本 | 恰好一个提交；另一返回 CONFLICT，不覆盖赢家 |
| 原请求重试及改变载荷 | 同请求仅一份结果；改变输入冲突，版本不重复增加；终态审核拒绝封住迟到成功并恢复编辑 |
| 审核通过/拒绝/超时/异常、超长/非法文本 | 仅通过的合法文本保存；使用 scene 3、服务端可信 openid |
| 审核延迟、事务已暂存时移除 B；B 离开并重入 | 旧操作不能提交或复活；离开后的共享内容保留 |
| 读取查询期间移除 B | 响应返回前再次鉴权，不能返回受保护内容 |
| 逐写点故障及丢失提交确认 | 完整回滚或通过原回执恢复，不重复创建或更新 |
| 多实例限流、Schema/索引、clientDB CRUD | 限额不可绕过，索引实际可用；六个业务集合直接 CRUD 均拒绝 |

只记录经过目标厂商实测的精确事务冲突码；不得从字符串猜测后加入生产重试配置。故障探针另需限定授权，使用后清除并恢复正常工件。
