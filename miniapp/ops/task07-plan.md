## 共享契约

所有业务调用沿用现有登录态；变更调用携带成员上下文和 requestId，云端从认证上下文确定上传者。下表为本票接口边界，DTO 在实施时按既有 `home-contracts` 模式定义并同步全部调用方。

| 接口 | 输入与输出 |
| --- | --- |
| `MediaApi.requestUpload` | 成员上下文、requestId、用途、MIME、声明字节数；返回 mediaId 与 5 分钟上传期限 |
| `MediaApi.upload` | 对应授权的成员上下文、mediaId、Base64 内容；通过现有登录态中转上传，关联原授权与请求恢复 |
| `MediaApi.complete` | 对应 mediaId；核验实际存储内容并提交审核，重复调用不重复提交 |
| `MediaApi.status` | 当前成员上下文与最多 20 个 mediaId；批量返回处理/审核状态 |
| `MediaApi.read` | 当前成员上下文与 mediaId；业务接口检查当前可见范围，返回临时 URL 与实际到期时间 |
| `RecipesApi.bindImages` | 成员上下文、requestId、菜谱 ID、version、imageIds；原子保存图片关联并返回更新后的菜谱/版本 |

用途为 `recipe-image`、`import-input`。后者不能绑定为菜谱图片。上述接口的读取范围不扩展为对平台 SDK 直接换链的拒绝保证。
