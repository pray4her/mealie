## 页面范围与验证证据职责

1. `account/login`：微信单一入口、请求中、匿名失败/重试、暂时无法确认、隐藏后的迟到登录结果；已有家庭默认进入菜谱，无家庭由菜谱守卫进入引导，邀请续接优先进入加入页。
2. `family/onboarding`：创建、原请求恢复、输入校验、冲突、持有邀请、网络失败、退出登录。
3. `family/home`：真实家庭名/角色、所有者与成员不同入口、重新校验、无家庭/身份失效、双 Tab 返回与状态隐藏。
4. `family/invite`：创建/恢复、分享、有效/过期/已用/撤销、分页、失败和隐藏时敏感凭据清除。
5. `family/join`：手动邀请码/分享续接、已有家庭限制、确认/恢复、失败及成功进入菜谱。
6. `family/members`：本人/角色、所有者移除和转移、普通成员退出、身份核对、原请求恢复及权限变化。
7. `recipes/index`：标题搜索/精确标签/收藏组合、已加载结果/继续查找、首次和后续页错误、各类空状态、独立收藏、私有首图、隐藏和家庭代次失效。
8. `recipes/detail`：完整菜名/作者/标签、可用份数和时间、原文及未知数量、长步骤、收藏恢复、图片授权/审核/失败/到期刷新。
9. `recipes/edit`：全部结构化字段、食材/步骤增删、校验、原请求恢复、共享编辑冲突/确认重载、文字/图片独立保存、键盘和安全区。
10. `imports/submit`：输入标签和限制、第三方处理/七天留存/自动保存说明、提交/恢复优先、失败、原文清除。
11. `imports/status`：真实排队/运行/成功/失败/取消、成功后查看和编辑、隐藏停轮询/返回重查、取消竞争、账号/家庭代次清理。

以上是验收范围；自动业务回归、编译检查、fixture 渲染、微信开发者工具和真机各自证明不同内容。未提供对应截图/设备记录的状态不因列入此清单而视为视觉通过。

## 组件与导航决定

依赖锁定 `@wot-ui/ui@2.4.0`、`sass@1.98.0`；保留 Vue 3.4.21、Vite 5.2.8、uni-app `3.0.0-5030420261029002`。`pages.json` 使用官方 npm easycom 路径。`src/styles/theme.scss` 覆盖 Wot 语义变量及 page/light/portal 范围，移除全局所有按钮绿色。

已对照 Wot v2.4.0 标签的快速开始、主题、按钮及安装包源码。官方全量 `@wot-ui/ui/global` 在当前 uni-helper 下触发未使用 canvas/video 组件的六个类型错误；本次 `src/wot.d.ts` 只声明实际使用组件的真实 SFC 类型，不放宽应用检查、不改依赖源码、不升级框架。引入其他 Wot 控件时沿用该实际类型声明方式。

主导航仅“菜谱 / 家庭”两个原生 Tab。`resetPage` 对真实 Tab 使用 `switchTab`，其余鉴权/流程重定向使用 `reLaunch`；`backPage` 优先返回原生页面栈，无法返回时进入对应 Tab。登录先处理邀请续接；否则进入菜谱，由现有守卫核实家庭，避免新增一套登录专用家庭查询。创建/加入成功均进入菜谱。

正式产物检查要求精确 11 页和上述两个 Tab，并拒绝未来空白模块及离线 fixture 标识。所有页面使用原生导航栏处理顶部安全区和返回。

## 与预览的明确差异

- 未交付的计划/加购/评论/评分和统计不显示；无图、待审核和失败显示真实状态，不借用预览照片。
- 独立搜索和精确标签筛选保留已有接口语义，不从分页结果构造全量标签库或总量。
- 编辑保留结构化食材和原文；文字保存与已有菜谱图片维护继续分开。
- 采用 16px 正文、44px 最小命中区、真实未知值和长文本；不复刻预览的小字、34px 标签或固定手机外壳。
