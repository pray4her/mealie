依据用户提供的已确认计划执行。源代码基准 `842a0ee11400dc2888f5c41caf1da4a75f8acec3`。

## Global constraints

- 仅客户端 UI，11 页；不变更云对象、数据库、RecipeInput、RecipesApi、MediaApi、导入契约。
- 复用 features 与现有服务、权限、家庭代次、幂等、恢复、冲突和私有媒体逻辑。无生产 mock。
- 只增加真实复用的业务组件，通用控件用 Wot，不新增通用框架/状态管理。
- 保留 uni-id 依赖，不升级 Vue/Vite/uni-app。无 GitHub 更新、发布、云部署或付费 AI。
- 原生导航栏；仅菜谱/家庭两 Tab；登录及创建/加入成功默认菜谱，邀请续接优先加入确认。
- 手机 320/375/390/430px、常规和大字号、44px 点击区、正文16px、底部安全区/键盘；不能伪称设备验收。
- 非平凡逻辑先补行为测试并观察失败。保留真实交互回归，不使用空 Wot 桩。
- 每任务完成自查、提交、记录 RED/GREEN 和检查结果；最终完整检查 `task -d miniapp check -- --maxWorkers=2`。

## Task 1: Wot、主题和真实登录页验证

锁定 `@wot-ui/ui@2.4.0` 和 `sass@1.98.0`，按实际版本官方文档配置 easycom 和全局类型。当前 Vue/Vite/uni-app 不变。
读取相关调用方、测试和配置。主题集中在应用主题文件，页面及弹层覆盖 Wot 语义变量；白内容面、`#F7F8F7` 背板、`#216840` 主操作、`#202923` 正文、`#667269` 辅助，移除全局所有按钮绿色。
登录页简洁品牌介绍、单一微信登录主按钮、原位错误/重试/忙碌。保留认证与异步代次，不改成功目的地（Task 2 统一）。不添加假输入框。
测试挂载工具实现 Wot 按钮 click/禁用/忙碌、输入 update:modelValue 与 input/confirm、textarea、action-sheet 的实际事件和值绑定；仅实现用到的控件行为。
完成登录交互测试、类型检查和真实微信构建（按钮、反馈及组件集成）。确认兼容后才迁移其余页面。记录确切命令与结果、官方来源及版本。

## Task 2: 原生导航与全部调用方

遍历所有导航和守卫调用方及测试。`pages.json` 配置原生导航栏、真实标题和菜谱/家庭两个原生 Tab；已有家庭用户默认进入菜谱，创建/加入成功同样进入菜谱，邀请跨登录续接优先加入。
Tab 页面用 switchTab；详情/编辑/邀请/成员/导入为页面栈，鉴权重定向与退出清栈正确。普通返回走原生栈/回退到合适 Tab；检查冷启动、双 Tab、子页返回、退出/移除/转移后与重加入流程。旧异步响应不得恢复旧家庭内容。
同步完善测试工具原生导航支持和行为测试，先 RED 后 GREEN。无新业务契约。

## Task 3: 私有封面与菜谱三页

列表显示真实家庭名、简短主标题、独立有标签标题搜索与精确标签筛选（可展开，维持提交/分页语义）；Wot 添加面板仅手动创建/AI 文本导入；明确最近任务/保存恢复/收藏恢复提示。全部/个人收藏与当前已加载数量、继续查找；不得伪造总量或从分页伪造标签库。
双列真实条目：4:3 私有封面、两行菜名、真实作者和可用时间，独立收藏；320px 或系统大字号单列。分别呈现首次加载、空家庭、收藏空、无匹配、扫描段空但可继续、加载错误、后续页失败。
封面使用首个已绑定图片 ID，经 `client.media.status/read`，按20个上限分批，不用单例 media.initialize。短期链接仅页面内存；筛选变化/隐藏/退出/家庭代次变化使旧请求失效并清空。到期或加载失败可刷新/重试；无图/审核中/拒绝/错误不同占位。新增异步行为测试先 RED 后 GREEN。
详情：菜图 → 标签/全称/作者 → 份数与时间 → 简介 → 食材 → 编号步骤；编辑收藏保留。食材名称/数量分列，原文、处理备注和未知数量完整；长步骤自然增长。现有媒体控制器补全图片加载失败/到期重试呈现。
编辑分基本信息/食材/步骤/标签/图片，保留全部结构化字段、增删、校验、原请求恢复、冲突与重新加载确认。先文字保存再已有菜谱维护图片，独立图片保存不能覆盖草稿。忙碌禁用、安全区、键盘。无计划/加购/评分/评论。
只提取实际复用业务组件。同步所有测试交互（支持Wot真实事件）；运行相关测试/类型检查/微信构建。

## Task 4: 家庭五页重构

读取原有脚本/业务与测试，保留真实权限、恢复、身份核对与确认内容，主要改布局/排版/控件。
onboarding 清楚分创建家庭、持邀请加入、已有家庭，创建/加入分区；home 真实家庭名和角色，以分组行组织成员、所有者邀请、退出登录；无统计。
invite 分新邀请、分享、有效/过期/撤销、分页与请求恢复；join 突出确认、已有家庭限制与未确认请求恢复。
members 姓名/角色/本人标识的行布局，所有者移除/转移与成员退出分开，危险操作文字明确。
Wot通用控件；普通返回/退出登录次级，危险操作不可全绿色。原生分享保留。44px点击与16px正文，长名称自然换行。同步真实交互测试并验证类型和微信构建。

## Task 5: AI两页与交付验证
